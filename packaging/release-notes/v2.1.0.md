## Screen Vibe Recorder 2.1.0

The first release of Screen Vibe Recorder. It is Desktop Recorder 2.0.0 plus the changes below. The program inside is still named Desktop Recorder (`DesktopRecorder.exe`).

### Changes

**"Changes only" keeps fewer still frames.**
On a still screen, the video now keeps one frame each 60 s. Before, it kept one frame each second. An AI that reads the frames now gets the same screen content from fewer frames.

**Small changes are no longer lost.**
In "Changes only" mode, the FFmpeg default thresholds dropped a one-character change, for example "x.y" to "x,y". The filter now keeps a frame when any 8x8 pixel block changes by more than 64 (`mpdecimate=hi=64:lo=64:frac=0`).

**Release files.**
- The archives have new names: `screen-vibe-recorder-2.1.0-windows-x64.zip` and `screen-vibe-recorder-2.1.0-linux-x86_64.tar.gz`.
- `DesktopRecorder.exe` is also attached alone. Use it to update a copy that you already have.
- `SHA256SUMS.txt` gives the SHA-256 of each file.
- The Windows zip script no longer fails on a GitHub runner (a path such as `D:\a\_temp` became an escape sequence).

### Known limits

- With "Changes only", the length of the file is correct to 60 s. A still part at the end of a recording can be missing from the file length, but not from the content.
- A tool that reads a video at a fixed rate (for example, 1 frame each second) makes copies of the frames again. Such a tool gets no gain from "Changes only".
- The Ubuntu archive holds the earlier full-screen recorder. It has no region selector. The Ubuntu port of the 2.0 features is on the `linux-port` branch and is not released.
- Not tested on Windows yet: the new "Changes only" values. The test with FFmpeg 6.1 on Linux passed (130 s with one small change gave 4 frames).

### Update an existing copy (Windows)

1. Exit Desktop Recorder (tray icon, then Exit).
2. Download `DesktopRecorder.exe` from this release.
3. Put it in place of your old `DesktopRecorder.exe`.
4. Start it. Your settings stay in `%APPDATA%\DesktopRecorder\settings.txt`.

### New install

Download the zip for your system, unzip it, and read `README.txt`. You must install FFmpeg yourself (Windows: `winget install -e --id Gyan.FFmpeg`).
